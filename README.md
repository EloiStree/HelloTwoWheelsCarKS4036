For workshop, I have bought 8 x (KS4036 + SSD1306 + ESP32 Sense Camera)

**The idea is to learn:**   
- Easy topic:   
  - Godot by recreating the car.
  - Godot Script by using the SSD1306
  - Modding in Godot
- Hard topic  
  - Control the real one with bluetooth from laptop
  - Control by the ESP32 Wifi from the Quest
  - Learn to recover the image of the ESP32 in Quest.
  - Learn IoT
